A combined vulnerability impact calculator and security posture quiz, built as a self-contained web tool to assess organizational security exposure.

## Features

- **Vulnerability Impact Calculator**: Estimates undiscovered vulnerabilities by analyzing your architecture and dependencies, comparing exposure windows with and without AI-assisted scanning.
- **Security Posture Quiz**: Evaluates readiness across Secure Design, AI Integration, and Internal Readiness categories. Produces a letter grade with tailored action items.
- **Combined Results**: Delivers a unified report merging both assessments with personalized recommendations based on score tier.
